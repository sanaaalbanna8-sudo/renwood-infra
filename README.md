# مصمم البنية التحتية: رينواد تورز

موقع ثابت يساعد طالب وحدة أنظمة تكنولوجيا المعلومات (BTEC مستوى 3) على بناء بنية رينواد تورز عبر أسئلة اختيار، ثم يخرج ملخصاً للتقرير. كل شيء يعمل في المتصفح، والإجابات تُحفظ في مفتاح `renwood-infra` داخل `localStorage`.

## التشغيل

```bash
npm install
npm run dev
npm test
npm run build
```

مجلد `dist` جاهز لـ GitHub Pages. التوجيه يستعمل الهاش (`/#/wizard/1/0`) فلا حاجة لإعادة توجيه الخادم. صفحة المعلم مخفية عن الطلاب: `/#/teacher`.

## إضافة سؤال

1. افتح `src/data/questions.ts`.
2. أضف عنصراً داخل `questions` بالدالة `q`: المعرّف، رقم المرحلة من 0 إلى 8، النوع (`single` أو `multi` أو `text`)، التسمية القصيرة، نص السؤال، ثم مصفوفة الخيارات.
3. اختر معرّفاً جديداً لا يكرر معرّفاً موجوداً. لا تغيّر معرّفاً قديماً لأن قوالب القصة وقواعد التناقض وملفات الطلاب تعتمد عليه.
4. إن كان السؤال يخدم أحد الاحتياجات، أضف معرّفه في `src/data/needs.ts`.
5. شغّل `npm test`.

المرحلة 9 ليست أسئلة. بنود العدد والموقع في `src/data/quantities.ts`.

## إضافة خيار

أضف النص داخل مصفوفة `options` للسؤال نفسه. أبقِ الخيارات القديمة كما هي حرفياً، لأن جواب الطالب المحفوظ وقاعدة التناقض يطابقان النص.

لإظهار سطر «معلومة» اكتب `hint` على السؤال. ولشرح سبب خيار بعد اختياره أضف `why` بالشكل `{ 'نص الخيار': 'السبب' }`. ولشرح معنى خيار تحت نصه أضف `gloss` بنفس الشكل، من غير أن تغيّر نص الخيار نفسه.

## تعديل قالب القصة

الجمل في `src/data/storyTemplates.ts`، والمنطق في `src/lib/story.ts`.

- المتغير يُكتب بين قوسين مثل `{ج1}` أو `{اسم الطالب}` أو `{الاحتياجات المغطاة}`.
- `{الاحتياجات المغطاة}` يُستبدل بالاحتياجات التي أُجيب سؤال واحد على الأقل من أسئلتها في `src/data/needs.ts`.
- إن بقي أي متغير في الجملة بلا جواب تُحذف الجملة كلها.
- الفقرة تُحذف إن بقي فيها أقل من جملتين.
- الخيار الذي يبدأ بـ«لا » أو «بلا » إذا كان الاختيار الوحيد لا يدخل الجملة، ويُذكر في آخر الصورة العامة.

قواعد التحذير (لا تمنع المتابعة) في `src/lib/rules.ts`.
